# tractor-lops

Tractor LOPs is a set of HDAs for submitting jobs to Pixar's Tractor Engine renderfarm service from within the Solaris LOP context. Tractor LOPs aims to streamline renderfarm submission to an intuitive, Solaris-native process.

With Tractor LOPs, artists can quickly set up and spool render layers, or wedge test different render settings by splitting their node stream.

Tractor LOPs supports spooling jobs for all Hydra delegates in Solaris. Additionally, it supports the RenderMan Denoiser (including AOV passes) when using Karma or RenderMan.
